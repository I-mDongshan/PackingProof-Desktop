Configure flags: third_party/ffmpeg/configure-flags.txt
Build dependencies: third_party/ffmpeg/versions.env
Pinned binary identity: tools/ffmpeg-baseline.json

The build enables GPL components and statically links FFmpeg with zlib, GnuTLS,
libx264, libx265, ffnvcodec/NVENC, AMF and Intel Media SDK/libmfx. It does not
enable libass, vmaf, webp, srt, SSH, AV1 software encoders or other unused
external libraries.

The corresponding FFmpeg source, build recipe, exact configure flags and direct
MSYS2 package versions are published in the PackingProof-Desktop repository.
Upstream source for the linked libraries is available from the MSYS2 package
archive referenced by those pinned package versions.
