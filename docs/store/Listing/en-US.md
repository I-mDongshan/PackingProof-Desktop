# Microsoft Store English listing

## App name

PackingProof

## Short description

Barcode-triggered packing videos, searchable by tracking number

## Description

Start recording by scanning a shipping label, and find the right video by tracking number when a customer asks.

PackingProof is a packing-video and shipment-evidence tool for e-commerce packing stations. It starts recording when a tracking barcode is scanned, saves the video against that tracking number, and lets you search the recording later.

Key features

- Event pre-record buffer: keeps the moments before the scan so the recording starts before the trigger
- Barcode-triggered recording from a camera or keyboard-style barcode scanner
- Recording, order details, time and workstation linked by tracking number
- Optional spoken order notes and buyer messages
- Refund warning after a label has been printed
- Multi-workstation upload from phones and other computers
- LAN playback in a browser with access control
- Local disk, removable drive and NAS storage policies
- Extension market: optional userscripts and external adapters for ERP, weighing devices and other integrations
- Watermark, recording statistics and storage-space warnings

Data stays on the device or in the storage location you choose. The Microsoft Store edition updates through Microsoft Store. Optional extensions, scripts and external adapters can be installed from the in-app extension market.

Open source: https://github.com/PackingProof/PackingProof-Desktop
