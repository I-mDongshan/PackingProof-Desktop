# Microsoft Store 中文文案

## 应用名称

PackingProof 快递打包监控

## 简短说明

扫码自动录像，按快递单号保存。支持订单播报、退款拦截、局域网回放与多工位备份

## 详细说明

打包就录像，售后找得到。

PackingProof 是面向电商打包台的录像与发货留证工具。扫描快递单号后自动开始录像，打包结束自动保存，并按快递单号归档。需要核实售后时，输入单号即可回放对应视频。

主要功能

- 事件预录：扫码触发前保留一段缓冲，录像开头不丢关键动作
- 扫码自动录像：摄像头识别面单条码，也支持键盘模式扫码枪
- 按单号归档：录像、订单信息、时间与设备自动关联
- 订单信息播报：联动快递助手，播报买家留言、卖家备注与商品信息
- 打印后退款拦截：发现已退款订单时播报告警，减少错发
- 多工位集中备份：手机与其他电脑可作为录像来源上传到主机
- 局域网回放：手机、平板或其他电脑通过浏览器按权限查看录像
- 本地/NAS 存储：录像保存在本机、可移动盘或 NAS，支持容量策略
- 扩展市场：可选安装用户脚本与外部适配器，接入 ERP、称重设备等
- 水印与统计：画面水印、录像统计与存储空间提示

数据默认保存在本机或你选择的存储位置。商店版由 Microsoft Store 自动更新；扩展、脚本和外部适配器可在软件内按需安装。

开源项目：https://github.com/PackingProof/PackingProof-Desktop

## 主要功能（Key features）

- 面单条码触发录像，按快递单号归档
- 事件预录缓冲：录像开头保留扫码前的关键动作
- 订单备注、买家留言与商品信息语音播报
- 打印后退款订单告警
- 手机与其他电脑多工位集中备份
- 局域网浏览器回放与按单号搜索
- 本地磁盘、可移动盘与 NAS 存储
- 画面水印、录像统计与容量提示
- 可选扩展市场与开放扩展 API（ERP、称重设备等）
